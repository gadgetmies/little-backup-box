## Cross-cutting findings

- `src/pages/Home.jsx` exists on disk (42 KB) but is **not mounted in any route**. `App.jsx:38` mounts `Backup` at `/`. Home.jsx is dead code that duplicates Backup.jsx; it should be deleted in a separate cleanup.
- The PHP rsync server config landed in `src/pages/Integrations.jsx` rather than `Network.jsx` (Plan 09). Functional but at a different location than the plan describes.
- `conf_idle_power_off` (Plan 13) uses a different config key than the PHP-side `conf_POWER_OFF_IDLE_TIME`. Either the backend bridges them or the config is being silently ignored — needs investigation.
- 44 translation keys were missing from `webapp/public/lang/*.json` and have been added in this branch; many more keys for unimplemented features still exist in the lang files and should not be removed until the corresponding plan lands.
